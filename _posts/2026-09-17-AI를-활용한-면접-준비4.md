```
# 대중 무역 정책 찬반 토론

기준일: 2026-09-17

미국의 현재 대중 무역 정책 및 제재가 한국 산업에 미치는 장단점

실시간 외부 검증 없음. 양측 수정안까지 진행. 일시적 오류는 최대 2회 재시도.

## 1. Codex · 찬성 · 독립 주장

저는 미국의 대중 무역 제재가 **한국의 일부 산업에 경쟁 기회와 공급망 다변화의 유인을 제공한다는 조건부 찬성** 입장이다. 다만 기업의 수혜가 국내 생산·고용 증가나 한국 전체의 순이익을 뜻하지는 않는다.

**[확인 필요]** 기준일은 2026년 9월 17일이다. 공통 근거자료와 실시간 검증이 없으므로 개별 정책의 최신 세율·적용 범위·시행 여부는 단정하지 않는다. 아래는 **정책이 해당 범위에서 시행된다는 가정에 따른 작동 경로와 전망**이다. 발표일과 시행일은 별개이며, 시행 중·유예·제안 상태를 확인하기 전에는 실제 효과로 확정할 수 없다.

**P1. 대중 관세는 배터리·자동차의 미국 시장에서 한국 기업의 대체 공급 기회를 만들 수 있다.**

- **정책 수단 → 경로 → 이익:** [가정·전망] 중국산 배터리·자동차에 한국산보다 높은 관세가 적용되면 중국산의 상대 가격이 올라 한국 기업의 수주·판매 기회가 커질 수 있다. 반도체는 사양·인증·생산능력이 거래를 크게 좌우하므로 관세만으로 대체가 일어난다는 주장은 더 제한적이다.
- **성립 조건:** 원산지 규정상 한국 기업 제품이 불리한 적용을 받지 않고, 가격·품질·납기를 충족해야 한다. 단기에는 기존 설비의 여유가, 중장기에는 투자 수익성이 중요하다.
- **반례·손실:** 중국산 소재·부품의 비용까지 상승하거나 중국 기업이 다른 시장에서 가격을 낮추면 한국 기업의 이익은 줄어든다. 미국 현지 생산 확대는 한국 기업의 이익일 수 있지만 국내 완성품 수출을 대체할 수도 있다.
- **확인할 자료:** 품목별 관세의 발표·시행일과 예외, 원산지별 실효 관세, 판매가격·점유율·수익률, 국내 및 해외 공장별 생산·고용.

**P2. 첨단 반도체 수출통제는 기술 경쟁의 시간을 벌 수 있지만, 한국의 중국 사업에도 직접 비용을 부과한다.**

- **정책 수단 → 경로 → 이익:** [가정·전망] 중국의 특정 첨단 장비·기술 접근이 제한되면 해당 분야의 추격이 늦어져 한국 반도체 기업의 기술 우위 유지에 도움이 될 수 있다. 이는 수입가격을 바꾸는 관세와 달리 기술 접근을 제한하는 경로다.
- **성립 조건:** 통제가 실제 기술 병목에 작용하고 우회조달이 제한되어야 한다. 한국 기업의 중국 내 공장 운영·장비 교체에 필요한 허가도 확보되어야 한다.
- **반례·손실:** 단기에는 중국 고객에 대한 판매와 현지 공장 업그레이드가 위축될 수 있다. 중장기에는 중국의 국산화가 빨라지거나 범용 제품 공급이 늘어 한국 기업의 다른 사업을 압박할 수 있다. 따라서 첨단 분야의 잠재 수혜를 반도체 전체의 이익으로 확대할 수 없다.
- **확인할 자료:** 통제 대상 기술·최종사용자, 허가·예외의 범위와 유효기간, 중국 매출 및 생산 비중, 경쟁사의 기술 진전과 한국 기업의 추가 투자비.

**P3. 투자 제한은 중국을 대체하는 생산·기술 협력 수요를 만들 수 있다.**

- **정책 수단 → 경로 → 이익:** [가정·전망] 미국의 대중 투자 제한이 특정 분야의 자본·경영 지원을 줄이면 일부 투자가 한국 또는 한국 기업과의 협력으로 이동할 수 있다. 다만 투자 제한 자체는 한국 투자에 대한 보조금이나 구매 보장이 아니다.
- **성립 조건:** 제한 대상 투자와 한국의 기술·생산 역량이 맞아야 한다. 반도체 분야의 제한을 배터리·자동차에도 동일하게 적용된다고 가정해서는 안 된다. 국내 이익을 위해서는 연구개발·소재·장비 발주가 국내에 연결되어야 한다.
- **반례·손실:** 자본이 미국이나 다른 국가로 이동하면 한국 국내 수혜는 작다. 중장기에는 중복 설비와 공급망 분리 비용이 발생하며, 중국의 보복이나 핵심 소재 공급 차질이 잠재 이익을 상쇄할 수 있다.
- **확인할 자료:** 투자 제한의 적용 방향·분야·거래 유형과 시행 상태, 투자 이전의 실제 행선지, 국내 부가가치·고용, 중국 의존도와 대체 조달 비용.

제 찬성은 **범위가 명확하고 한국 기업의 전환 비용을 줄이는 정책 설계**에 한정된다. 한국 산업의 수혜 가능성만으로 미국 정책 자체가 정당해지는 것은 아니다. 정책의 정당성은 안보 목적과 수단의 연관성, 비례성, 국제규범과 제3국 비용을 별도로 검토해야 한다.

## 2. Claude Code · 반대 · 독립 주장

# 독립 주장 (반대 측 — 비용과 위험 중심)

**입장 전제**: 미국의 대중 무역 제재는 관세, 수출통제, 투자제한이라는 서로 다른 수단으로 구성되며, 이들이 한국 산업에 미치는 경로와 크기는 다릅니다. 아래는 각 수단별로 구분한 독립 주장입니다. [확인 필요]: 2026-09-17 기준 각 조치의 정확한 시행 상태(시행 중/유예/제안)는 최신 공식 발표로 재확인이 필요합니다.

---

**N1. 반도체 대중 수출통제 → 한국 메모리 기업의 대중 생산 불확실성 확대**
- **정책 수단**: 미 상무부(BIS)의 첨단 반도체 장비·기술 대중 수출통제(가정: 검증된 최신 라이선스 조건 및 갱신 여부는 확인 필요).
- **작동 경로**: 삼성전자·SK하이닉스의 중국 내 생산법인(시안, 우시 등)이 특정 예외 허가(예: VEU 방식으로 알려진 제도, [확인 필요])에 의존해 설비를 반입해왔는데, 규제가 강화되거나 예외가 재검토될 경우 설비 업그레이드가 지연됨.
- **손실**: 대중 생산라인의 노후화, 원가경쟁력 약화, 생산 이전(국내·미국 등) 비용 발생.
- **성립 조건**: 예외 허가가 불확실하게 유지되거나 실제로 축소되는 경우.
- **반례**: 예외가 사실상 영구화되거나 완화되면 영향은 제한적이며, 오히려 국내 신규 투자(온쇼어링) 유인으로 작용할 수 있음 — 이는 찬성 측 논리와 일부 겹치는 지점으로 인정함.
- **확인할 자료**: BIS 최신 규정 원문, 개별 기업의 라이선스 갱신 발표.

**N2. 중국의 대응 조치(희토류·핵심광물 수출통제) → 배터리·반도체 소재 공급망 리스크**
- **정책 수단**: 미국 조치에 대한 중국의 보복성 수출통제(희토류, 흑연 등 배터리·반도체 소재, [확인 필요: 구체 품목과 시행 여부]).
- **작동 경로**: 한국 배터리(LG에너지솔루션, 삼성SDI)·반도체 소재 조달이 중국산 원자재·중간재에 상당 부분 의존 → 이는 미국 정책의 직접효과가 아니라 **중국의 보복에 따른 간접·공급망 효과**로 구분해야 함.
- **손실**: 원가 상승, 조달 불안정, 생산 차질 가능성.
- **성립 조건**: 중국이 실제로 광범위한 보복 조치를 발동하고 한국이 이를 회피하지 못하는 경우.
- **반례**: 호주·인도네시아 등으로 공급망 다변화가 상당히 진전되었다면 영향은 제한적 — [확인 필요: 다변화 진척도].
- **확인할 자료**: 중국 상무부 수출통제 품목 리스트, 한국 기업의 소재 조달처별 비중.

**N3. 대중 고율관세 → 한국 기업의 중국 내 생산기지 우회수출 타격**
- **정책 수단**: 대중국 고율관세(성격상 관세이지 수출통제·투자제한과는 구분됨, [확인 필요: 최신 세율·품목]).
- **작동 경로**: 한국 기업의 중국 내 생산법인(자동차부품, 가전 등)이 미국向 수출을 해왔을 경우, 원산지 규정 강화와 관세 부과로 대미 수출경쟁력이 저하되고 생산기지 재편(베트남 등 제3국 이전) 비용이 발생.
- **손실**: 단기적으로 대중 생산법인의 수익성 악화, 중장기적으로 이전 비용 부담. 다만 이는 **한국 국내 생산**이 아니라 **한국 기업의 해외(중국) 생산**에 국한된 영향임을 구분해야 함.
- **성립 조건**: 해당 기업의 대중 생산기지가 유의미한 규모로 미국向 수출에 의존하는 경우.
- **반례**: 이미 다수 기업이 베트남·인도 등으로 생산을 이전 완료했다면 영향은 제한적일 수 있음.
- **확인할 자료**: 한국 기업의 중국 내 생산법인별 대미수출 비중, 관세 품목·세율 최신 공고.

---

**공통 유보**: 세 주장 모두 특정 산업(반도체 일부·배터리·자동차부품)에 국한되며, 이를 "한국 산업 전체의 순손실"로 일반화하지 않습니다. 반도체 파운드리·비메모리 등 일부 영역은 오히려 대중 경쟁사 견제로 반사이익을 볼 가능성도 있어 [확인 필요] 표시로 남겨둡니다.

## 3. Codex · 찬성 · 교차 검토

상대는 **N1**에서 반도체 장비 수출통제와 허가 불확실성이 한국 기업의 중국 공장 경쟁력을 약화시킬 수 있다고, **N2**에서 중국의 대응이 소재 조달 비용과 생산 차질을 초래할 수 있다고, **N3**에서 대중 관세가 중국에서 생산해 미국에 판매하는 한국 기업에 불리하다고 주장한다. 모두 조건부 위험이며, 한국 전체의 순손실로 일반화하지 않았다는 점은 타당하다. 찬성 측의 검토 대상은 위험의 존재보다 **발생 조건·규모와 기회이익을 함께 비교했는가**이다.

**검토 전제 — [확인 필요]** 제공 발언은 독립적으로 검증된 사실 자료가 아니다. 아래는 가정에 따른 인과 검토다. 정책별 발표일·시행일, 2026-09-17 당시 시행 중·유예·제안 여부가 확인되지 않았으므로 실제 피해나 수혜가 발생했다고 단정하지 않는다.

**PR1 → N1: 중국 공장의 비용과 반도체 사업 전체의 손익은 구분해야 한다.**

- **인정:** [가정·전망] 필요한 장비 반입 허가가 축소되면 업그레이드 지연과 이전 비용이 발생할 수 있다. 국내 투자가 늘더라도 기존 해외 자산의 손실이 자동으로 상쇄되지는 않는다.
- **반박:** 허가의 ‘불확실성’에서 실제 장비 반입 지연, 생산성 저하로 이어지는 단계가 입증되지 않았다. 통제가 어떤 공정과 제품에 적용되는지도 중요하다. 동시에 중국 경쟁사의 첨단 기술 접근까지 제한된다면 한국 기업이 다른 생산거점에서 얻는 경쟁상 이익이 누락된다. 다만 첨단 경쟁사의 제약이 한국 메모리 제품의 이익으로 이어진다는 보장도 없다.
- **가장 강한 반례·실패 가능성:** [가정] 한국 기업의 필수 장비 반입은 허용되고 중국 경쟁사의 기술 병목은 지속되는 경우, 중국 공장 손실은 작고 경쟁상 이익은 남을 수 있다. 반대로 중국이 병목을 극복하면 찬성 측의 이익 경로가 약해진다.
- **필요한 검증:** 허가 범위·기간, 실제 반입 지연, 공정별 투자 필요, 중국 경쟁사의 기술 진전, 국내·해외 거점별 비용과 수익. 예외의 영구화만이 아니라 예측 가능한 허가도 위험을 줄일 수 있다.

**PR2 → N2: 공급망 위험은 인정하지만 ‘미국 정책 때문에 생긴 피해’의 범위를 입증해야 한다.**

- **인정:** [가정·전망] 중국의 공급 제한과 높은 조달 의존도가 겹치면 단기 생산 차질이 가능하다. 공급처 변경에도 인증·정제·가공 능력 확보 비용이 든다.
- **반박:** 중국 조치를 모두 미국에 대한 보복으로 규정하면 인과관계를 과도하게 단순화한다. 미국 조치가 없었을 경우에도 존재했을 공급 위험과 추가 위험을 나눠야 한다. 또한 광범위한 보복이 없어도 대체하기 어려운 한 품목의 제한만으로 피해가 클 수 있어, 상대의 성립 조건은 지나치게 좁다. 희토류·흑연 등을 배터리와 반도체에 묶어 적용하지 말고 공정별로 구분해야 한다.
- **가장 강한 반례·실패 가능성:** [가정] 한국행 공급이 유지되고 중장기 다변화가 실제 대체 능력을 확보한다면 피해는 제한되고 공급 안정성이 개선될 수 있다. 다만 중국 밖에서 채굴하더라도 정제·가공을 중국에 의존하면 이 반례는 성립하지 않는다.
- **필요한 검증:** 통제 품목과 허가 실적, 실제 납기·가격 변화, 기업별 재고와 공정별 의존도, 대체 공급의 가동 시점. 자동차도 소재·부품 경로를 별도로 점검해야 한다.

**PR3 → N3: 중국산에 대한 타격과 한국산의 대체 기회를 함께 비교해야 한다.**

- **인정:** [가정·전망] 중국 원산지 제품에 추가 관세가 적용되고 해당 법인의 미국 매출 비중이 크면 수익성 악화가 가능하다.
- **반박:** 중국 공장의 정상적인 대미 수출을 ‘우회수출’로 부를 근거는 없다. 관세 부과와 원산지 규정 강화도 별도 조치이므로 각각 확인해야 한다. 중국 공장의 손실과 함께 국내 공장의 대체 수출, 미국 현지 공장의 판매 증가를 비교해야 한다. 해외 법인 손실도 국내 본사의 배당·투자 여력이나 국내 중간재 수요에 파급될 수 있어 영향이 해외 생산에만 국한된다는 표현은 좁다.
- **가장 강한 반례·실패 가능성:** [가정] 중국 공장이 내수 중심이고 국내 공장에 여유 설비가 있다면 직접 손실은 작고 대체 수출 기회는 클 수 있다. 제3국 이전만으로 관세 회피가 보장되지는 않는다.
- **필요한 검증:** 생산지·원산지별 실효 관세, 법인별 판매처, 국내 증산 능력, 이전 비용과 국내 부가가치. 배터리·완성차·부품의 결과를 동일시해서는 안 된다.

**검토 결론:** 세 위험 경로는 인정하되, 기회이익과 비교한 규모는 판단 보류한다. 상대는 투자 제한을 별도로 평가하지 않았으며, 제 분석의 투자 유입 전망 역시 아직 입증되지 않았다. 찬성 입장은 일부 산업의 조건부 기회로 유지한다. 이것이 한국 전체의 순이익이나 미국 정책의 정당성을 증명하지는 않으며, 정당성은 안보 목적·비례성·국제규범을 별도로 검토해야 한다.

## 4. Claude Code · 반대 · 교차 검토

# 교차 검토: 찬성(Codex) 독립 주장에 대한 반대 측 검토

## 상대 주장 요약
Codex는 조건부 찬성으로, P1(대중 관세→배터리·자동차 대체수주 기회), P2(반도체 수출통제→기술 우위 시간 확보, 단 중국 매출·현지공장 비용 발생), P3(투자제한→대중국 대체 협력 수요)를 제시하며, 각 주장에 성립조건과 반례를 스스로 명시했습니다. 기업 수혜를 한국 전체 순이익으로 일반화하지 않는다는 전제도 명확합니다.

---

**NR1 (P1 검토 — 관세발 대체수주론)**
- **인정**: 원산지 규정 충족 시 단기 대체수주 가능성 자체는 타당한 경로이며, 반도체는 사양·인증 장벽으로 관세 대체효과가 제한적이라는 구분도 동의합니다.
- **누락·가정**: "중국산 가격 상승 → 한국 수주 증가"는 한국 기업이 **여유 생산능력**을 보유하고 있음을 전제합니다. 그러나 배터리·자동차 부품 다수는 이미 완전가동에 가깝거나 증설에 수년이 걸려, 단기에는 대체수주보다 **가격 인상·물량 배분 협상력** 정도로 그칠 수 있습니다.
- **인과관계 취약점**: 중국의 보복관세·수출통제(제 N2와 연결)로 한국 기업의 원가도 함께 상승하면, 상대가격 우위가 상쇄되어 순이익이 예상보다 작아질 수 있습니다. 이는 P1이 다루지 않은 **간접효과**입니다.
- **가장 강한 반례**: 미국 현지 생산 요건(IRA식 조건, [확인 필요])이 강화되면 한국의 대체수주 자체가 "한국 국내 수출"이 아니라 "한국 기업의 미국 현지 생산"으로 흡수되어, 상대측이 스스로 인정한 것처럼 국내 수출 대체 효과가 발생합니다.
- **판단**: 조건부 인정 — 성립조건(여유 생산능력, 원산지 유리성)이 충족될 때만 유효. 규모는 과대평가 위험.

**NR2 (P2 검토 — 수출통제 기술우위론)**
- **인정**: 통제가 실제 병목 기술에 작용하고 우회조달이 막힐 때 기술격차 유지에 기여한다는 논리, 그리고 단기 중국 매출·현지공장 위축을 손실로 명시한 점은 균형 잡힌 서술입니다.
- **누락**: "기술 우위 유지"가 곧 "매출·이익 증가"로 이어지는 경로가 빠져 있습니다. 경쟁사(중국) 추격 지연이 한국 기업의 판매량 증가로 전환되려면 **시장 자체가 확대**되거나 **점유율 이전**이 일어나야 하는데, 이는 별도 검증이 필요한 추가 가정입니다.
- **실패 가능성**: 상대측도 인정했듯 중국의 범용 반도체 국산화·증산이 가속화될 경우, "시간을 버는 이익"이 "범용 시장 잠식이라는 손실"로 상쇄되어 순효과가 음수일 가능성도 배제할 수 없습니다.
- **가장 강한 반례**: 제 N1(대중 생산법인 설비 노후화)과 정면으로 충돌합니다 — 같은 수출통제가 상대측에서는 "기술 우위 확보"로, 저희 측에서는 "대중 생산라인 불확실성"으로 나타나는데, 이는 **동일 정책의 수혜자(첨단 로직/설계)와 피해자(대중 메모리 생산법인)가 기업·사업부 단위로 갈릴 수 있음**을 시사합니다. 즉 "반도체 산업"으로 뭉뚱그리면 안 됩니다.
- **판단**: 부분 인정(논리 구조), 규모와 순효과 부호는 판단 보류.

**NR3 (P3 검토 — 투자제한발 협력수요론)**
- **인정**: 투자 제한 자체가 한국에 대한 보조금이 아니라는 점, 분야별로 동일시하면 안 된다는 자기제약은 타당합니다.
- **누락·가장 강한 반례**: 이탈 자본의 행선지가 한국이라는 보장이 없습니다. 실제로는 미국·인도·동남아로 이동할 가능성이 더 높다는 것이 상대측도 인정한 반례이며, 저희는 여기서 더 나아가 **한국이 오히려 중국의 투자·기술 협력 파트너에서 배제되는 비용**(예: 배터리 합작사 지분 조정 요구, [확인 필요])이 발생할 수 있다고 봅니다. 이는 P3에 없는 손실 항목입니다.
- **판단**: 근거 미약 — 협력수요 발생의 구체적 사례나 수치가 제시되지 않아 전망 수준에 머무름. 검증 전까지 회의적.

## 정리
- **수용**: P1·P2의 조건부 구조와 자기제약(순이익 일반화 금지)은 방법론적으로 타당.
- **기각/보류**: 세 주장 모두 "여유 생산능력", "시장 확대", "자본의 한국 유입"이라는 검증되지 않은 전제에 의존하며, 각각 저희 N1~N3의 반대 경로(설비 불확실성, 보복 공급망 리스크, 우회수출 타격)와 상쇄될 가능성이 큼.
- **추가 검증 과제**: (1) 배터리·부품 업계의 실제 가동률, (2) 첨단 vs 범용 반도체 사업부별 손익 분리 데이터, (3) 대중 투자 이탈 자본의 실제 행선지 통계.

| **P1** | “관세가 배터리·자동차의 대체 공급 기회를 만든다” → **[가정·전망]** 중국산과의 실효 관세 차이가 있고 대체 가능한 제품을 공급할 수 있을 때 기회가 생긴다. 단기는 재고·여유 설비에 따른 판매 증가 또는 가격 협상력 개선, 중장기는 증설 수익성이 핵심이다. | 관세 차이만으로 수주·이익 증가를 추론하지 않는다. 배터리는 고객 인증·소재 조달, 자동차는 차종·판매망 등 제약을 따로 평가한다. 반도체의 관세 대체효과는 기존처럼 제한적으로 본다. |
| **P2** | “수출통제가 기술 경쟁의 시간을 번다” → **[가정·전망]** 특정 기술 병목에서 경쟁 압력을 늦출 가능성은 유지하되, 경제적 수혜는 제품별 가격·수익성 방어 또는 판매 증가가 확인되어야 인정한다. | 기술적 효과와 상업적 효과를 분리한다. 단기 중국 고객 매출·현지 설비 비용, 중장기 중국 국산화·범용 공급 확대를 함께 반영한다. 첨단·범용 및 기업·사업부별 순효과는 판단 보류다. |
| **P3** | “투자 제한이 대체 생산·협력 수요를 만든다” → **[가정·전망]** 한국으로의 투자·협력 이전은 검증할 가설로 낮추고, 현재의 적극적 찬성 근거에서는 제외한다. | 제한된 투자가 다른 곳에서 재집행된다는 보장도 없다. 적용 방향·대상 거래를 확인하고, 한국 유입·국내 연구개발 연결과 협력 단절·중복 투자 비용을 비교해야 한다. |

세 주장 모두 **한국 국내 생산과 한국 기업의 해외 생산을 별도 집계**한다. 미국 공장의 수익 증가는 국내 생산·고용 증가와 같지 않으며, 중국 공장의 손실도 한국 전체 손실과 동일하지 않다. 관세·수출통제·투자 제한의 직접효과와 중국 대응·소재 공급 차질의 간접효과도 구분한다. 중국 조치를 미국 정책의 ‘보복’으로 귀속하려면 별도 근거가 필요하다.

**수정된 입장:** P1의 시장 접근 기회와 P2의 제한적인 경쟁 압력 완화 가능성에 근거한 조건부 찬성을 유지한다. 다만 현행 정책 전체의 한국 순이익을 입증한 주장은 아니다. 한국 산업의 수혜 가능성과 미국 정책의 안보상 필요성·비례성·국제규범상 정당성은 별도 판단한다.

**남은 이견:** 기회의 실현 규모, 비용과의 상쇄 정도, 기술 우위의 수익성 전환 여부다. 상대가 제시한 완전가동·투자 행선지 우위도 아직 확인되지 않았다.

**검증할 주장 3개**

1. **P1: 관세가 추가 이익을 만드는가?** 원산지별 실효 관세, 가동률·주문·마진, 공장별 생산 자료가 필요하다. 수요 변화·보조금 효과를 분리하고 추가 조달·전환 비용을 차감해 판정한다.
2. **P2: 기술 경쟁상 이익이 직접 비용을 웃도는가?** 통제·허가 범위, 기술 진전, 사업부별 손익·설비투자 자료가 필요하다. 통제가 없었을 경우와 비교해 제품별로 판정한다.
3. **P3: 제한 때문에 한국 투자·협력이 늘었는가?** 거래별 이전 경위·행선지·국내 부가가치 자료가 필요하다. 기존 예정 투자를 제외하고 제한과의 인과관계 및 협력 축소 비용을 확인한다.

모든 검증은 기준일까지의 자료로 한정하며, 정책별 **발표일·시행일·시행 중/유예/제안 상태**를 먼저 확인한다.

# 반박·수정 (반대 측 — Claude Code)

## 1. 쟁점별 수용·기각·판단 보류

## 2. 수정 전후

**N1 (수정)** — 전: "허가 불확실성 → 업그레이드 지연 → 원가경쟁력 약화"를 단선적 인과로 제시. 후: 허가 축소가 **실제 설비 반입 거부·지연으로 확인된 경우에 한해** 손실이 발생하며, **중국 경쟁사도 동일 통제를 받는 경우** 상대적 손실 규모는 줄거나 상쇄될 수 있다는 조건을 추가. 이유: 인과 단계 입증 부족 지적을 반영.

**N2 (수정)** — 전: "중국의 대응 조치(보복성 수출통제)"로 규정. 후: "미국 조치와 무관하게 존재하던 위험과, 미국 정책에 대응해 추가된 위험을 구분해야 하며, 후자만 이 주제의 논거로 유효"로 수정. 성립 조건도 "광범위한 보복 발동"에서 "단일 핵심 품목이라도 대체 불가능한 경우"로 완화. 이유: 인과 귀속 단순화 및 성립 조건 협소 지적을 반영.

**N3 (수정)** — 전: "우회수출 타격", "해외 생산에만 국한". 후: "정상적 대미 수출 경로를 가진 중국 내 생산법인의 원가경쟁력 저하"로 표현 수정, "국내 대체 생산·미국 현지 생산 증가로 상쇄될 수 있는지는 기업별로 확인해야 하며, 해외 법인 손실이 본사 배당·국내 협력사 발주 감소로 파급될 가능성도 함께 검토"로 비교 프레임 추가. 이유: 부정확한 용어와 비교 누락 지적을 반영.

**공통 유보(유지)** — 세 위험 모두 특정 산업 국한이며 한국 전체 순손실로 일반화하지 않는다는 원래 전제는 상대도 이의 없이 수용했으므로 유지.

## 3. 수정된 입장

반도체 수출통제·중국의 조달 위험·대중 관세는 각각 **다른 발생 조건**을 가진 조건부 위험이며, 손실 규모는 **동일 정책이 만드는 기회이익(찬성 측 P1~P3)과 함께 비교해야 확정된다**는 입장으로 좁힌다. 위험의 존재 자체는 유지하되, 크기·순효과는 판단 보류.

**남은 이견**: (1) 중국의 조치를 "미국 정책 대응"으로 얼마나 귀속시킬 수 있는지, (2) 반도체 통제가 중국 경쟁사에도 동등하게 작용하는지, (3) 해외 법인 손실의 국내 파급 정도.

**검증할 주장 3개**
1. N1 — BIS 최신 규정상 한국 기업 라이선스(구 VEU 방식) 갱신·거부 실적 → 필요 자료: 상무부 공고 원문, 기업 공시
2. N2 — 중국 수출통제 품목별 한국 기업의 대체 조달처 확보 시점 → 필요 자료: 산업통상자원부·기업 조달 공시, 판정 기준: 대체 물량이 기존 조달의 30% 이상 확보 여부
3. N3 — 한국 기업 중국 생산법인의 대미 수출 비중과 관세 적용 세율 → 필요 자료: 관세청·기업 IR 자료, 판정 기준: 해당 법인 매출 중 대미 비중이 유의미(예: 10% 이상)한지
```

// Some CLI wrappers print banners, update notices, or debug logs to stdout
// ahead of the actual JSON payload, which breaks a naive JSON.parse(output).
// Try a straight parse first, then fall back to extracting the outermost
// {...} object before giving up.
export function parseClaudeOutput(output) {
  try {
    return JSON.parse(output);
  } catch {
    const match = output.match(/\{[\s\S]*\}/);
    if (!match) {
      throw new Error(`Claude 응답에서 JSON을 찾을 수 없음: ${output.slice(0, 500)}`);
    }
    return JSON.parse(match[0]);
  }
}

// Commands are fixed strings. User text is passed only through stdin, never into shell code.
export function invokeCli(stage, prompt, cwd) {
  const command = stage.agent === 'Codex'
    ? `${process.platform === 'win32' ? 'codex.cmd' : 'codex'} exec --skip-git-repo-check --sandbox read-only --ephemeral --color never -`
    // '-p -' explicitly tells the CLI to read the prompt from stdin rather than
    // expecting it as a trailing argument after -p.
    : 'claude -p - --output-format json --tools "" --strict-mcp-config --disable-slash-commands --permission-mode dontAsk --no-session-persistence';
  const output = execSync(command, {
    cwd, input: prompt, encoding: 'utf8', timeout: 300000,
    maxBuffer: 10 * 1024 * 1024, windowsHide: true, stdio: ['pipe', 'pipe', 'pipe'],
  });
  if (stage.agent === 'Codex') return output.trim();
  const result = parseClaudeOutput(output);
  if (result.is_error || typeof result.result !== 'string') {
    throw new Error(`Claude 응답 실패: ${JSON.stringify(result)}`);
  }
  return result.result.trim();
}

// Transient failures (rate limits, timeouts, dropped connections) are worth a
// couple of retries with backoff; anything else (bad input, empty response,
// auth failure) is not, so we fail fast on those instead of wasting a 5-minute
// timeout window three times over.
const RETRYABLE_PATTERN = /429|rate.?limit|timeout|timed out|ETIMEDOUT|ECONNRESET|EPIPE|overloaded|fetch failed|temporarily unavailable/i;

function sleepSync(ms) {
  const buf = new SharedArrayBuffer(4);
  Atomics.wait(new Int32Array(buf), 0, 0, ms);
}

export function invokeWithRetry(invoke, stage, prompt, cwd, { retries = 2, baseDelayMs = 3000 } = {}) {
  let attempt = 0;
  for (;;) {
    try {
      return invoke(stage, prompt, cwd);
    } catch (error) {
      const text = [error.message, error.stderr?.toString(), error.stdout?.toString()].filter(Boolean).join('\n');
      if (attempt >= retries || !RETRYABLE_PATTERN.test(text)) throw error;
      attempt += 1;
      const delay = baseDelayMs * 2 ** (attempt - 1);
      console.log(`  일시적 오류로 재시도 ${attempt}/${retries} (${delay}ms 대기): ${stage.id}`);
      sleepSync(delay);
    }
  }
}

export function runDebate(root, spec, invoke = invokeCli, { retries = 2, retryBaseDelayMs = 3000 } = {}) {
  mkdirSync(path.join(root, 'runs'), { recursive: true });
  const dir = mkdtempSync(path.join(root, 'runs', 'trade-'));
  writeFileSync(path.join(dir, 'spec.json'), JSON.stringify(spec, null, 2), 'utf8');
  const transcript = path.join(dir, 'transcript.md');
  writeFileSync(transcript, `# 대중 무역 정책 찬반 토론\n\n기준일: ${spec.asOf}\n\n${spec.topic}\n\n실시간 외부 검증 없음. 양측 수정안까지 진행. 일시적 오류는 최대 ${retries}회 재시도.\n`, 'utf8');
  const answers = [];
  for (const [index, stage] of stages.entries()) {
    const prompt = buildPrompt(index, answers, spec);
    writeFileSync(path.join(dir, `${stage.id}-prompt.txt`), prompt, 'utf8');
    console.log(`${index + 1}/6 ${stage.agent} (${stage.side}): ${stage.phase}`);
    try {
      // Each invocation starts fresh in a separate directory without earlier answer files.
      const cwd = mkdtempSync(path.join(tmpdir(), 'trade-debate-'));
      const answer = invokeWithRetry(invoke, stage, prompt, cwd, { retries, baseDelayMs: retryBaseDelayMs }).trim();
      if (!answer) throw new Error('빈 응답');
      writeFileSync(path.join(dir, `${stage.id}.md`), answer, 'utf8');
      appendFileSync(transcript, `\n## ${index + 1}. ${stage.agent} · ${stage.side} · ${stage.phase}\n\n${answer}\n`, 'utf8');
      answers.push(answer);
    } catch (error) {
      writeFileSync(path.join(dir, `${stage.id}-error.txt`), [error.message, error.stderr?.toString(), error.stdout?.toString()].filter(Boolean).join('\n'), 'utf8');
      appendFileSync(transcript, `\n진행 중단: ${stage.id}. 후속 호출 없음.\n`, 'utf8');
      return { ok: false, dir, completed: answers.length };
    }
  }
  return { ok: true, dir, completed: answers.length };
}

// evidence는 6번의 호출 프롬프트마다 그대로 반복 포함되므로, 지나치게 큰 파일이
// 입력 토큰을 6배로 불리거나 컨텍스트 한도를 넘지 않도록 길이를 제한한다.
const DEFAULT_EVIDENCE_MAX_CHARS = 8000;

function loadEvidence(filePath, maxChars) {
  const raw = readFileSync(path.resolve(filePath), 'utf8').replace(/^\uFEFF/, '');
  if (raw.length <= maxChars) return raw;
  return `${raw.slice(0, maxChars)}\n\n[...이하 생략: 전체 ${raw.length.toLocaleString('ko-KR')}자 중 앞 ${maxChars.toLocaleString('ko-KR')}자만 포함됨. 필요하면 --evidence-max-chars로 늘리거나 자료를 사전에 요약하세요.]`;
}

function main() {
  const values = parseCliArgs(process.argv.slice(2));
  if (values.run && values.preview) throw new Error('--run과 --preview 중 하나만 지정하세요.');
  const asOf = values['as-of'] ?? new Intl.DateTimeFormat('sv-SE', { timeZone: 'Asia/Seoul' }).format(new Date());
  if (!/^\d{4}-\d{2}-\d{2}$/.test(asOf) || !Number.isFinite(Date.parse(asOf)) || new Date(asOf).toISOString().slice(0, 10) !== asOf) {
    throw new Error('--as-of는 유효한 YYYY-MM-DD 날짜여야 합니다.');
  }
  const evidenceMaxChars = values['evidence-max-chars'] ? Number(values['evidence-max-chars']) : DEFAULT_EVIDENCE_MAX_CHARS;
  if (!Number.isFinite(evidenceMaxChars) || evidenceMaxChars <= 0) {
    throw new Error('--evidence-max-chars는 양의 정수여야 합니다.');
  }
  const spec = {
    topic: '미국의 현재 대중 무역 정책 및 제재가 한국 산업에 미치는 장단점',
    asOf,
    successCriteria: '양측 독립 주장, 상대 주장별 교차 검토, 받은 지적별 수용·기각·판단 보류, 수정안과 검증 과제',
    evidence: values.evidence ? loadEvidence(values.evidence, evidenceMaxChars) : '공통 자료 없음. 최신 사실 확인 필요.',
  };
  console.log(`기준일: ${asOf}\nCodex 찬성 / Claude Code 반대\n각 3회, 총 6회 호출. 호출별 제한 5분, 일시적 오류는 최대 2회 재시도(그 외 오류는 즉시 중단).`);
  stages.forEach((s, i) => console.log(`${i + 1}. ${s.agent}: ${s.phase}`));
  if (!values.run) {
    console.log('\n미리보기: AI 호출 및 결과 저장 없음. 실행: node .\\trade-debate.mjs --run');
    return;
  }
  const result = runDebate(path.dirname(fileURLToPath(import.meta.url)), spec);
  console.log(`${result.ok ? '완료' : '중단'}: ${result.completed}/6\n기록: ${result.dir}`);
  if (!result.ok) process.exitCode = 1;
}

if (process.argv[1] && path.resolve(process.argv[1]) === fileURLToPath(import.meta.url)) {
  try { main(); } catch (error) { console.error(error.message); process.exitCode = 1; }
}
